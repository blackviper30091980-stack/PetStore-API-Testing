     TEST PLAN
1. Project Overview
Project: Swagger PetStore API

Objective: to verify the functionality, reliability and correctness of the Swagger Petstore API by executing positive and negative test scenarios.

2.Scope

The following API modules are included in testing:
- Pet
- Store
- User
  
The following operations will be tested:
- Get
- Post
- Put
- Delete

3. Test Objectives
The purpose of testing is to verify:
- correct processing of API requests
- correct HTTP status codes
- response body accuracy
- validation of input data
- error handling
- CRUD operations

4. Test Types
- functional testing
- positive testing
- negative testing
- API testing
- flow testing

5. Test Environment
Item             Value
API              Swagger Petstore
Base URL         https://petstore.swagger.io/v2
Tool             Postman
Data format      JSON

6. Test Deliverables
- test plan
- test data
- positive test cases
- negative test cases
- flow testing
- bug reports
- postman collection
- test summary report

7. Entry Criteria
Testing may start when:
- swagger petstore API is available
- postman is configured
- test data is prepared

8. Exit Criteria
Testing is completed when:
- all planned test cases have been executed
- test results are documented
- defects are reported

9.Risks
- temporary API unavailability
- public API dat may change
- unexpected server responses
